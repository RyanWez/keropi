TL;DR — ဖုန်းနံပါတ်က BCD အဖြစ်နဲ့ ထည့်ထားတာပဲ

KBZPay ရဲ့ ငွေလက်ခံ (Receive) QR ထဲမှာ ဖုန်းနံပါတ်ကို BCD encoding နဲ့ တိုက်ရိုက်ထည့်သွင်းထားတာကို တွေ့ရှိခဲ့ပါတယ်။ App က QR ထဲက အချက်အလက်ကို ကိုယ်တိုင် စစ်ဆေးပြီး လုပ်ဆောင်တာ မဟုတ်ဘဲ — server ကို ပို့လိုက်ပြီးမှ၊ server ဘက်ကမှ string ကို စိတ်ဖြာ (parse) ပြီး ဖုန်းနံပါတ်ကို ဖတ်ယူကာ ဆက်သွယ်ရမယ့် အကောင့်ကို လုပ်ဆောင်ပါတယ်။

🔑

အဓိက တွေ့ရှိချက်

QR ထဲက template bytes တွေက မည်သည့်အခါမှ မပြောင်းလဲပါဘူး။ ဒါကြောင့် မှန်ကန်တဲ့ template တစ်ခုနဲ့ ဖုန်းနံပါတ်ရဲ့ BCD ကို လက်ဖြင့် တည်ဆောက်နိုင်ရင် — မည်သည့် ဖုန်းနံပါတ်အတွက်မဆို KBZPay server လက်ခံမယ့် ငွေလက်ခံ QR ကို ဖန်တီးနိုင်ပါတယ်။

ဖုန်းနံပါတ် ရိုးရိုးကို တိုက်ရိုက် QR လုပ်ပြီး Scan လုပ်လို့ မရတဲ့ အကြောင်းရင်း

📤

Scanner က ချက်ချင်း server ကို ပို့လိုက်တယ်

ScanNewFragment.analysisResult က scan ရရှိလာတဲ့ string ကို app ထဲ (local) မှာ စစ်ဆေးခြင်း မရှိဘဲ ScanQRCode2 command နဲ့ server ကို တန်းပို့လိုက်ပါတယ်။

🧩

Server က ကိုယ်ပိုင် format လေးကိုပဲ နားလည်တယ်

Server က KBZPay ကိုယ်ပိုင် TLV format ကိုပဲ ဖတ်တတ်ပါတယ်။ ဖုန်းနံပါတ် ရိုးရိုး (ဥပမာ 09123456789) ဖြစ်နေရင် “QRကုဒ် မမှန်ကန်ပါ။” ဆိုတဲ့ error နဲ့ ပြန်ပယ်ချပါတယ် — res/values-my-rMM/strings.xml:657။

kbzpay_qr.py

အောက်ပါ script လေးက အပေါ်မှာ ရှင်းပြထားတဲ့ အဆင့်များအတိုင်း QR string ထုတ်ပေးပြီး PNG ဖိုင်လည်း သိမ်းပေးပါတယ် (pip install qrcode လုပ်ပြီးမှ အသုံးချပါ) —

kbzpay_qr.py 
import base64, time, qrcode

ALPHA = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"
HEAD  = bytes.fromhex("85064b425a50617961404f02f0500210510231315716")
TAIL  = bytes.fromhex("260910101f9f080401019f240130")

def bcd(phone: str) -> bytes:
    # ဂဏန်း ၁၁ လုံး (မကွဲညီ) → 'D' ထည့်ဖြည့်ပြီး 6 bytes ဖြစ်အောင်လုပ်
    d = phone if len(phone) % 2 == 0 else phone + 'D'
    return bytes(int(d[i:i+2], 16) for i in range(0, len(d), 2))

def kbzpay_qr_string(phone: str, ts_ms: int | None = None) -> str:
    ts  = ts_ms or int(time.time() * 1000)
    tlv = HEAD + bcd(phone) + TAIL            # 42 bytes ဖြစ်ရမယ်
    s   = base64.b64encode(tlv).decode()       # 56 chars
    chk = ALPHA[sum(int(d) for d in str(ts)) % 64]
    return s + "F" + chk + format(ts, 'x') + "=="

# ဖန်တီးပြီး PNG သိမ်း
img = qrcode.make(kbzpay_qr_string("09123456789"))
img.save("qr.png")

လုပ်ဆောင်ချက် အဆင့်လိုက်

  1. BCD ပြောင်းဖုန်းနံပါတ်ကို ဂဏန်း ၂ လုံးစီ ခွဲပြီး 1 byte အဖြစ် ပြောင်းပါတယ်။ မကွဲညီ (odd) ဖြစ်နေရင် အဆုံးမှာ 'D' ထည့်ဖြည့်ပါတယ်။
  2. TLV တည်ဆောက်HEAD + BCD + TAIL ဆက်လိုက်ရင် 42-byte payload ရပါတယ်။
  3. base64 encode42 bytes ကနေ စာလုံး အတိအကျ 56 လုံး ရပါတယ်။
  4. Suffix ဆက်"F" + checksum အက္ခရာ + timestamp (hex) + "==" ကို အဆုံးမှာ ဆက်ပေးလိုက်ပါတယ်။
  5. QR ထုတ်ရလာတဲ့ string ကို qrcode library နဲ့ PNG ပုံအဖြစ် ထုတ်ယူပါတယ်။

Scan ပြီးတိုင်း နာမည် ပြန်စစ်ပါ

Transfer မျက်နှာစာ ပေါ်လာတဲ့ လက်ခံသူရဲ့ နာမည်က နောက်ဆုံး safety net ပါ။ QR ဘယ်လောက် သေချာနေနေ — နာမည် မမှန်ရင် ငွေ မလွှဲပါနဲ့။

⛔

ရည်ရွယ်ချက် အပြင်ဘက် မသုံးပါနဲ့

ဒီနည်းလမ်းက ငွေလွှဲတဲ့ business တွေမှာ ဖုန်းနံပါတ် မှားတတ်တာ (typo) လျှော့ချဖို့အတွက်သာ ဖြစ်ပါတယ်။ အခြား ရည်ရွယ်ချက်နဲ့ အသုံးချခြင်းကို ရှောင်ကြဉ်ပါ။

ℹ️

QR ကို မြင်သူတိုင်း လုပ်နိုင်တာက ငွေပို့ရုံပါ

QR ထဲက အကောင့်နံပါတ်ကို ဘယ်သူ့ကိုမဆို သိသွားစေနိုင်ပေမယ့် သူတို့ လုပ်နိုင်တာက အဲ့ဒီ အကောင့်ကို ငွေပို့လိုက်ရုံပါပဲ — အကောင့်ကနေ ငွေထုတ်ယူလို့ မရပါဘူး။
